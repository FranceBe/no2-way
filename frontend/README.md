# Frontend

React + TypeScript app built with Vite. It shows London weather, air quality and transport data served by the API in `../backend`.

Use the Node version from `../.nvmrc` (`nvm use`).

## Scripts

| Command             | What it does                                                               |
| ------------------- | -------------------------------------------------------------------------- |
| `npm run dev`       | Dev server with mocked API (MSW)                                           |
| `npm run build`     | Type-check and production build, against the real API                      |
| `npm run lint`      | ESLint                                                                     |
| `npm run storybook` | Component library on http://localhost:6006                                 |
| `npm test`          | All Vitest projects in watch mode (unit + stories)                         |
| `npm run test:unit` | Unit tests only (jsdom)                                                    |
| `npm run test:e2e`  | Playwright end-to-end tests (`npx playwright show-report` after a failure) |

## API and mocks

The API URL and the mock switch come from `.env.development` and `.env.production`:

- In dev, `VITE_USE_MOCKS=true`: [MSW](https://mswjs.io) answers every request with generated data from `src/mocks/`.
- To use the real API in dev, run `VITE_USE_MOCKS=false npm run dev`, or put `VITE_USE_MOCKS=false` in `.env.development.local` (not committed).

`public/mockServiceWorker.js` is generated by MSW: don't edit it. If mocks stop working after an `npm install`, regenerate it with `npx msw init public`.

## Project structure

```
src/
  api/             fetch client, react-query queries, API types
  mocks/           MSW handlers and generated data (dev only)
  theme/           design tokens (tokens.css), light/dark theme logic
  ThemeToggle/     Auto / Light / Dark switch
  WeatherWidget/   current weather card and its icons
  AirQualityWidget/ European AQI chart, pollutant charts
  test/            shared test setup: MSW server, renderWithProviders
e2e/               Playwright scenarios
```

Each component folder holds its component, styles, stories (`*.stories.tsx`) and tests (`*.test.tsx`).

## Design system

All colours live in `src/theme/tokens.css` (light and dark). See **Design System/Tokens** in Storybook for the palette and typography. Fonts (Inter, Space Grotesk) are self-hosted from npm and licensed under the SIL Open Font License.

## Tests

- Unit tests use the shared MSW server from `src/test/server.ts`: declare responses with `server.use(...)`. Requests without a handler fail the test.
- Render components that fetch data with `renderWithProviders` from `src/test/render.tsx`.
- E2E tests run the app without MSW and stub the API with `page.route`.
